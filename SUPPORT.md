# Support

Read [installation](docs/self-hosting.md) and [troubleshooting](docs/troubleshooting.md) first.
For a bug, open an issue in [this repository](https://github.com/highsierraloft/callrelay/issues).
Include the version, platform, and a reproduction with fictional data.
Do not send credentials, real contact details, device serials, recordings, or transcripts.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
This community project does not provide a hosted calling service or an uptime guarantee.
