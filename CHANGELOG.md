# Changelog

## 0.1.0 — Community preview

- Exported the calling platform and guarded Android gateway into a separate project.
- Added a portable setup tool and standalone Compose recipe.
- Made handset identity, SIM selection, and line labels operator settings.
- Added a separate Android application ID and signing-property prefix.
- Kept MCP calling, the private dashboard, personalities, practice, reception, memory, callbacks, and result files.
- Retained upstream notices and separate component licenses.
- Replaced installation audio with synthetic, reproducible fallback prompts.
- Updated Pipecat and compatible dependency locks to include published security fixes.

The new community package still requires handset acceptance on each operator's hardware.
